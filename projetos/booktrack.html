Sobre o projeto

O BookTrack nasceu como um estudo prático de API de produção — não só CRUD, mas as camadas que separam um protótipo de um serviço real: autenticação segura, controle de acesso por papel, modelagem de dados dimensional (Star Schema) e importação de acervo via CSV. O sistema permite cadastrar livros, acompanhar o progresso de cada leitura, registrar avaliações e citações, e expor uma view pública limitada do acervo para terceiros.

É dividido em duas partes com responsabilidades bem separadas: uma API REST em FastAPI, que concentra toda a regra de negócio e o acesso a dados, e um frontend server-side em Django, que consome essa API para oferecer a interface de uso.
